# Contributing to Antigravity Mobile Remote

Thank you for your interest in contributing! We welcome bug reports, feature requests, and pull requests.

## Getting Started
To get started with local development:
1. **Clone the repository:**
   ```bash
   git clone https://github.com/kik1211/Antigravity-IDE-Mobile-Remote.git
   cd Antigravity-IDE-Mobile-Remote
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure environment variables:**
   Copy `.env.example` to `.env` and set your `APP_PASSWORD`.
4. **Run locally:**
   ```bash
   npm start
   ```

## Development
- **Make focused changes:** Ensure each commit and PR addresses a single specific issue or feature.
- **Test before submitting:** Run the health checks and manually verify functionality on a mobile device or responsive emulator.
- **Keep unrelated changes out of PRs:** Do not refactor unrelated code.

## Pull Requests
- Explain what changed in the PR description.
- Explain why the change is necessary.
- Include testing steps so reviewers can verify your work.
- **Include screenshots for UI changes.**
- Keep commits focused and logically separated.

## Issues
- Search existing issues first to avoid duplicates.
- Provide reproducible steps when reporting bugs.
- **Do not include secrets** (passwords, tokens, `.env` files, etc.) in your issue reports.
